# Kế hoạch

1. Migration bảng chat, RPC gửi và thống kê quản trị, kiểm tra quyền bằng dữ liệu hoàn tác.
2. Tách điều khiển nhạc, thêm thanh âm lượng và ghi nhớ mức chọn.
3. Thêm trang 7, API/chat UI, lịch sử và cập nhật có điều kiện.
4. Mở rộng trang quản trị để quản lý chat, giữ các quyền hiện có.
5. Kiểm tra, cập nhật hướng dẫn, xuất bản và xác minh bản online.
