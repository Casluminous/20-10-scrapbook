# Kế hoạch

1. Tạo tài khoản chủ bằng Supabase Auth, lấy UID, bật đăng nhập khách ẩn danh.
2. Migration tạo quyền quản trị, thùng rác và lượt yêu thích; kiểm tra bằng SQL hoàn tác.
3. Bổ sung client API cho đăng nhập, phiên khách, yêu thích và API quản trị.
4. Thêm trái tim vào các thẻ lời chúc hiện có.
5. Tạo trang quản trị riêng với đăng nhập, tìm kiếm, lọc thùng rác, sắp xếp và khôi phục.
6. Kiểm tra lỗi/quyền/UI, xuất bản, xác minh phiên quản trị của chủ và gửi link riêng trong chat.
